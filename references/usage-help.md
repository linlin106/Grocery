# 使用帮助

## 你可以怎样调用

- “粗读这篇论文”：生成决策卡片、证据表、复现门槛判断和可视化摘要图。
- “精读这篇论文”：重建问题、变量、假设、模块、公式、流程、证据、局限和扩展方向。
- “帮我复现”：先做可行性审计，再拆成公式、模型、结果、扩展四层复现。
- “讲这个公式/图/实验”：按作用、符号、条件、机制、证据强度和实现映射讲解。

## 粗读输出

粗读不是摘要改写，而是投入决策。输出应回答：

1. 论文背景是什么？
2. 核心问题是什么？
3. 方法属于哪一类？
4. 主结果靠哪张图、哪张表或哪个实验支撑？
5. 创新点具体在哪里？
6. 复现门槛高不高？
7. 下一步应该停、保存、精读还是复现？

粗读结果末尾必须包含一张可视化摘要图。优先使用 Mermaid flowchart/mindmap；如果当前环境支持图片生成或图表渲染，也可以输出 PNG/SVG/Markdown image。图片应展示“背景 -> 问题 -> 方法 -> 证据 -> 决策”。

## 精读输出

精读围绕一条主线展开：

```text
问题 -> 研究对象/变量 -> 假设 -> 方法模块 -> 公式/算法 -> 求解/训练/评测 -> 结果 -> 局限 -> 改进
```

精读时不要逐句翻译。每个模块都要说明：它解决主线中的哪一步，输入是什么，输出是什么，和其他模块如何耦合，证据是否足够，哪里可能失效。

## 复现输出

复现从最低有用层级开始：

- 公式复现：先把符号、单位、推导接口和数值检查做清楚。
- 模型复现：先做最小可运行版本，验证输入输出、shape、损失/求解器和 sanity check。
- 结果复现：先选一个最能支撑主张的图表或指标，做原文/复现对照。
- 扩展复现：先写假设，只改一个主变量，再解释结果分支。

复现帮助应包括资源审计、仓库结构、环境策略、数据版本、运行记录、结果对照、偏差诊断、降级条件和最终判断。

## 常用模板

- `templates/rough-read.md`：粗读卡片。
- `templates/deep-read.md`：精读笔记。
- `templates/symbol-table.md`：符号表。
- `templates/reproduction-plan.md`：复现计划。
- `templates/reproduction-log.md`：实验日志。
- `templates/extension-plan.md`：扩展复现实验设计。

## 判断是否完成

- 粗读完成：能 2 分钟讲清论文解决什么、怎么做、凭什么可信、是否值得继续。
- 精读完成：关掉论文后能重建“问题-方法-证据-局限”的完整链条。
- 复现完成：不只代码跑通，还能给出参数、环境、数据、指标、对照表和偏差解释。
