# Literature Reading Coach Skill

面向研究生和科研人员的论文阅读与复现教练。它把一篇论文拆成三种不同任务：**粗读用于筛选与定位，精读用于重建论文逻辑，复现用于把“看懂”变成“做出来”**。

## 能做什么

- **粗读**：快速判断论文是否值得投入，输出一页决策卡片，并在末尾附一张可视化摘要图。
- **精读**：围绕“问题 -> 假设 -> 方法 -> 证据 -> 局限 -> 改进”重建论文主线，避免逐句翻译式阅读。
- **复现**：把复现拆成公式复现、模型复现、结果复现、扩展复现四层，帮助制定可执行、可降级、可诊断的复现方案。
- **教学检查**：每个阶段都提供理解检查问题，帮助用户确认自己不是“看过”，而是真的能讲清楚。
- **可保存成果**：配套模板可直接保存为阅读卡片、精读笔记、符号表、复现计划、实验日志和扩展实验设计。

## 适合的使用场景

- 上传或粘贴一篇论文，希望快速判断是否值得继续读。
- 需要把论文讲给导师、同学或组会听。
- 读公式、方法、图表时卡住，希望有人按主线拆解。
- 准备复现一篇论文，但不知道从公式、模型、结果还是扩展开始。
- 想把论文阅读过程整理成可归档笔记和可复查实验记录。

## 三层工作流

| 层级 | 目标 | 典型时间 | 主要产出 | 达标标准 |
|---|---|---:|---|---|
| 粗读 | 判断值不值得继续投入 | 20-45 分钟 | 粗读卡片 + 3 个待查问题 + 可视化摘要图 | 能 2 分钟讲清论文解决什么、怎么做、凭什么可信 |
| 精读 | 重建逻辑链与证据链 | 2-6 小时 | 结构化笔记 + 符号表 + 方法流程图 + 局限/扩展清单 | 不看论文也能讲清方法流程，并指出关键假设/风险 |
| 复现 | 重新生产或验证关键结果 | 1-4 周 | 复现计划 + 最小实现/推导 + 日志 + 结果对照表 | 过程可运行、可核验、可解释偏差 |

## 复现分层

| 层级 | 适合情况 | 最小产出 |
|---|---|---|
| 公式复现 | 公式密集、代码缺失、想先确认数学关系 | 推导笔记、符号表、数值检查、代码变量映射 |
| 模型复现 | 想做最小可运行版本 | 最小仓库、输入输出 shape、sanity check |
| 结果复现 | 想对齐论文核心图表或指标 | 原文/复现对照表、多次运行统计、偏差解释 |
| 扩展复现 | 想形成自己的研究增量 | 事先假设、单变量改动、新结果图表、解释分支 |

## 推荐提示词

```text
请用 literature-reading-coach 粗读这篇论文，输出决策卡片，并在最后附一张可视化摘要图。
```

```text
请精读这篇论文，重点帮我重建“问题-假设-方法-证据-局限”的主线，不要逐句翻译。
```

```text
请帮我制定复现计划：先评估代码、数据、依赖、硬件和指标，再判断应该从公式复现、模型复现还是结果复现开始。
```

```text
请把这篇论文的核心公式拆成符号表、推导接口、量纲检查和代码实现映射。
```

## 使用建议

第一次读一篇新论文时，先粗读，不要直接进入复现。粗读后如果论文价值不高，就停止或保存为背景；如果主线清楚但细节不足，再精读；如果目标是做实验，则先选择最低有用复现层级，避免一开始就追求完整复现全部结果。

最实用的停损规则：**粗读后不值得，就停；精读后做不动，就降级；结果复现受阻，就先做模型复现；扩展复现没有假设，就不要跑。**

更多功能说明见 `references/usage-help.md`。
